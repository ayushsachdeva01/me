# Ayush Sachdeva — Personal Site

GitHub Pages-ready personal landing page for Ayush Sachdeva.

## Deploy

Upload the contents of this folder to the `main` branch of the `ayushsachdeva01/me` repository and enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → / (root)**.

All project logos, the profile image, MonoCode logo/header, and the Englebert font are local assets.
